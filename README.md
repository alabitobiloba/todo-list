# To-Do List

A to-do list app built with HTML, CSS and JavaScript that lets you add tasks, strike them through when they are done, and delete them.

## Live Demo

[https://alabitobiloba.github.io/todo-list/](https://alabitobiloba.github.io/todo-list/)

## Features

- Type a task into the input box and add it to your list with a button
- Click a task to strike it through when it is done
- Click a struck-through task again to undo it
- Delete any task with the delete button next to it
- Clean, simple layout

## Built With

- HTML
- CSS
- JavaScript

## How It Works

The page has an input box where you write a task and a button that adds it to the list. When you click the button, JavaScript takes the text from the input and adds it to the list on the page as a new item, with a delete button beside it. Clicking a task switches a style on and off, which draws a line through the text when it is done and removes the line if you click it again. Clicking the delete button removes that task from the list.
