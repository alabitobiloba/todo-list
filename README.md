# To-Do List

A to-do list app built with HTML, CSS and JavaScript that lets you add tasks and strike them through once they are done.

## Live Demo

[https://alabitobiloba.github.io/todo-list/](https://alabitobiloba.github.io/todo-list/)

## Features

- Type a task into the input box and add it to your list with a button
- Click a task to strike it through when it is done
- Clean, simple layout

## Built With

- HTML
- CSS
- JavaScript

## How It Works

The page has an input box where you write a task and a button that adds it to the list. When you click the button, JavaScript takes the text from the input and adds it to the list on the page as a new item. When you click a task in the list, JavaScript gives it a style that draws a line through the text, so you can see it is finished.
